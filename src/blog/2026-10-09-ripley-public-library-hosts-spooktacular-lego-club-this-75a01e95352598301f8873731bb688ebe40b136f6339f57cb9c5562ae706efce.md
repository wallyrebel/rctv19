# Ripley Public Library Hosts Spooktacular Lego Club This Saturday

The Ripley Public Library is hosting Lego Club this Saturday, October 10, from 2:30 PM to 4:30 PM. The event features a spooky building theme perfect for the Halloween season.

Children are invited to bring their creativity and build something spooktacular using provided LEGOs. Suggested building ideas include haunted houses, pumpkin patches, friendly monsters, creepy castles, or any other Halloween-inspired creations. The library emphasizes that there is no wrong way to build, and participants can let their imaginations run wild.

The library provides all necessary LEGO materials, so families simply need to arrive ready to create. The event promises an afternoon of creativity, laughter, and Halloween fun for young builders and their families.
