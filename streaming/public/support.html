How can we help?

For help with the live player, TV apps, or on-demand programming, email myersgrouponline@gmail.com.

Include your device model, the program you were watching, the approximate time of the problem, and any error shown. Please do not send passwords or payment information.

If video will not play

  1. Check your internet connection.
  2. Return to the programming screen and select the video again. Use Refresh programming in the TV app if needed.
  3. Close and reopen the app, or reload the web player.
  4. If only the live feed is unavailable, try again shortly. A broadcast interruption may affect every device.

Using a TV remote

Choose Watch live or an available replay and press Select. Press Back to return to programming. Use the player's playback controls to pause, resume, or seek when the program supports it.

Watching on a website

Open watch.rctv19.com. Website owners can find the iframe code under “Put this player on your website.”
